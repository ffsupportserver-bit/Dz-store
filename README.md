# DZ-store
نسخة جديدة من متجر DZ-store مع لوحة إدارة مستقلة وربط Supabase.

## الروابط
- المتجر: `/`
- لوحة الإدارة: `/admin.html`
- يوجد أيضاً `/admin/index.html` كمسار بديل.

## Supabase
الواجهة تستعمل publishable key فقط. لا توجد كلمة سر Admin داخل الملفات. تسجيل دخول الأدمن يتم عبر Supabase Auth ثم يتم فحص `public.is_admin()`.

## قبل النشر
1. طبّق `sql/upgrade.sql` إذا كانت قاعدة البيانات تحتاج الترقية. الترقية الأساسية تم تجهيزها للمشروع الحالي.
2. ارفع كامل المجلد كما هو إلى الاستضافة.
3. افتح `/admin.html` وسجّل بحساب الأدمن الموجود في Supabase.
4. أضف المنتجات وطرق الدفع من لوحة الإدارة.

## ملاحظات
- لكل منتج رابط Demo ورابط Binance وكود Binance وملاحظة دفع مستقلة.
- الطلب لا يمكن تأكيده من المتجر بدون تسجيل دخول الزبون.
- لا تضع service_role key في الواجهة أو الملفات العامة.
